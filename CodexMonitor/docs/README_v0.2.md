# CodexMonitor v0.2 — Windows ChatGPT 桌面版自动恢复

## 启动与操作

直接双击 **`CodexMonitor_v0.2.ahk`**（需 AutoHotkey v2，目标电脑已安装），不需要 `.cmd`。

1. 保持 ChatGPT Windows 桌面版为当前前台窗口。
2. 按 **Ctrl + Shift + F12** 启动监控，出现右上角悬浮提示；再按一次即时停止。
3. 按 **Ctrl + Shift + F11** 切换「自动」和「测试（绝不点击）」模式；建议先切至测试模式，等待至少一个周期，确认日志后切回自动。
4. 脚本默认是**自动模式**，但双击运行后仍需按 F12 组合键才开始监控。
5. 完全退出：Windows 托盘右击 AHK 图标 → Exit。

## 核心保护规则

- **启动前严格验证**前台窗口进程名为 `ChatGPT.exe`，否则错误弹窗，拒绝监控。
- 启动后延迟约 650ms 首次检测，此后每 10 秒检测一次；快捷键线程不再同步执行扫描。
- 一次 `BitBlt` 截取输入栏附近的像素，再在内存中查找蓝色圆形及其中白色三角形/方形，减少数万次逐像素跨进程读取。
- 三角形连续三次识别成功，位置相差不大、无按键按下、保持原 ChatGPT 窗口前台，才允许单击一次。
- **点击前就锁定**，直到后续两个独立周期识别到方形才重新允许点击。无法识别时不点击。
- 切至测试模式不点击，也不会推进解锁状态。停用后任何正在进行的扫描都不能继续自动点击。
- 窗口切换/最小化/关闭时停止并报错。脚本不会在其他软件界面执行鼠标操作。

## 文件

- `CodexMonitor_v0.2.ahk`：第二版脚本，与原 `CodexMonitor.ahk` 并存。
- `CodexMonitor_v0.2.log`：每轮识别结果、耗时、候选坐标、二/三次确认、跳过原因及点击事件。
- `README_v0.2.md`：本说明。

## 建议的验收步骤

1. 在正常方形按钮下以测试模式运行，日志应记录 `square`，不点击。
2. 等到出现三角形，日志应记录 `triangle`，测试模式不点击。
3. 按 F11 切回自动模式，等待下一轮检测，日志应依次有检测1、2、3和**点击一次**。
4. 观察三角形如未消失，日志不能再次出现点击；方形连续两轮出现后才能解锁。
5. 长按或连续切换 F12，确认出现/消失悬浮提示，检查日志有明确的“启动/停止”事件。

## 自检

命令行可执行：

`"C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" /ErrorStdOut "CodexMonitor_v0.2.ahk" --self-test`

自检只在内存构造蓝色圆形 + 三角/方形样本，不会监控或点击鼠标。

如果要只读检查真实桌面截图识别，可在 ChatGPT 前台时执行 `"C:\\Program Files\\AutoHotkey\\v2\\AutoHotkey64.exe" /ErrorStdOut "CodexMonitor_v0.2.ahk" --screen-test`。此模式只读取一次屏幕并打印判断结果，绝不点击；如果当前进程没有桌面交互上下文，会打印 `SKIP`。

**限制**：屏幕像素识别需要窗口可见，窗口尺寸、DPI、主题或 ChatGPT UI 更新可能导致 `unknown`；不支持最小化状态。只识别按钮形状，无法判断任务是正常完成还是异常中断。自动点击仍存在截图与真实点击之间极短的竞态时间窗。
