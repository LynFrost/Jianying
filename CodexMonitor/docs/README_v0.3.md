# CodexMonitor v0.3 使用说明（方案 A）

## 文件及启动

- 主程序：`CodexMonitor_v0.3.ahk`，直接双击即可运行，不需要 CMD。目标 Windows 电脑已检测到 AutoHotkey v2。
- 运行后同目录生成 `CodexMonitor_v0.3.log`，记录检测结果、识别坐标、锁定状态、高频窗口开始和结束、解锁及点击。
- v0.1 的 `CodexMonitor.ahk` 和 v0.2 的 `CodexMonitor_v0.2.ahk` 已保留，本次未覆盖。

**重要：启动 v0.3 前，先在 Windows 系统托盘退出此前运行中的 v0.1 / v0.2。不同版本可能同时注册快捷键，造成两份监控争用或误点。**

## 快捷键

- **Ctrl + Shift + F12**：启动/停止监控。只有当前窗口是 `ChatGPT.exe` 桌面版才允许启动，其他前台窗口将弹出报错并停止。
- **Ctrl + Shift + F11**：在「自动模式」与「测试模式（绝不点击）」之间切换。脚本默认自动模式，但双击启动脚本后仍要按 F12 才开始监控。
- 右上角悬浮提示显示最近一次检测结果及锁定/快速检测状态。

## v0.3 的防重复点击状态机（方案 A）

1. **正常低频检测**：每 10 秒识别一次屏幕底部蓝色圆形按钮。如果连续三次识别为白色三角形，位置匹配、前台仍为同一个 ChatGPT 窗口、修饰键均已松开，才单击一次。
2. **点击后立即锁定**：锁定先于点击。完成点击后进入为期最多 **15 秒**的高频确认阶段，以约 **250ms** 间隔检查按钮。
3. **只有确认方形才解锁**：连续至少 **3 次**识别到白色方形，并且首末样本相隔 **不少于 500ms**，才解除锁定，恢复每 10 秒的普通监控。出现 `triangle` 或 `unknown` 时立即清空方形候选计数。
4. **15 秒没有稳定方形**：停止高频检测，返回每 10 秒检查，**但仍保持锁定，不再自动点击**。
5. **后来才看到方形**：如果处于锁定中的低频检查看到方形，会额外开启一个最多 **2 秒 / 250ms** 的确认窗口；只在方形满足稳定条件后解锁，否则继续锁定。
6. **停止和测试模式**：停止监控时停止计时器；切换测试模式时取消正在进行的高频监控但保留锁定，测试模式既不点击，也不推进解锁状态。

**方案 A 不包含点击无效后的超时重试。** 如果始终没观察到稳定的方形，就始终不能自动再次点击。这是刻意保留的防重复保护。

## 首次上机验证建议

1. 从托盘退出旧版本；双击 `CodexMonitor_v0.3.ahk`。
2. 按 Ctrl+Shift+F11 进入测试模式；再按 Ctrl+Shift+F12 开始监控。观察检测日志和悬浮提示。测试模式不会点击。
3. 再次按 F11 切回自动模式。Codex 中断时应看到一次“确认三角形三次，点击一次”，紧接着有“快速检测开始：postclick”。
4. 如果恢复时方形保持约 0.5 秒以上，日志应记录“锁定解除”；再次中断后才能再次触发点击。
5. 如果持续为三角形，15 秒后高频窗口应结束，日志保持 `lock=1`，不得出现第二次点击。
6. 用 Ctrl+Shift+F12 验证停止。日志文件出现后，可提供它以排查是否成功捕获短暂的方形。

## 非交互测试

安装 AutoHotkey v2 后，在该目录执行：

- `"C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" /ErrorStdOut "CodexMonitor_v0.3.ahk" --self-test`：语法、合成图标、方形稳定性自检；**无任何鼠标点击**。
- `"C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" /ErrorStdOut "CodexMonitor_v0.3.ahk" --capture-test`：截取极小的像素缓冲区，检查 GDI 通路，**无任何鼠标点击**。
- `--screen-test`：仅在本机前台存在 ChatGPT.exe 时做单次只读识别，**不点击**。

## 限制

这套程序只能识别肉眼可见的屏幕按钮形状，不能直接读取 ChatGPT 内部任务状态，也不能可靠地区分任务正常结束和异常中断。实际定时受 Windows 调度和系统负载影响，250ms 是目标间隔而不是硬实时保证；小于确认时长的短暂方形仍可能错过，但不会以超时为理由盲目再次点击。
