# ChatGPT Codex 自动恢复监控（AutoHotkey v2）

## 功能

- `Ctrl + Shift + F12`：启动/停止监控（启动前默认关闭）。
- 启动时必须让 **ChatGPT Windows 桌面版**处于前台，进程名须为 `ChatGPT.exe`；否则 Windows 弹出错误提示，不启动、不点击。
- 启动成功时显示悬浮“● 监控中”，立即检查一次，此后每隔 **10 秒**检查。
- 只有在底部蓝色按钮中 **连续三次识别到朝右的白色三角形**（其中后两次相隔很短时间）时，才自动单击一次。
- **先锁定再点击**：即使三角形一直保留，也不会每 10 秒重复点击。只有在后续两个 10 秒采样周期里连续识别到白色方形后，才允许下一次自动恢复。
- 窗口离开前台、最小化/关闭或识别异常时停止/不操作。图标未知、无法确认、尺寸不符，均不点击。
- `CodexMonitor.log` 自动记录状态变化与点击事件。

## 安装和运行

1. 已在目标电脑上检测到 `C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe`。如果以后换电脑，再从 [AutoHotkey 官网](https://www.autohotkey.com/) 安装 **AutoHotkey v2**（不是 v1）。
2. 在此目录双击 **`双击启动.cmd`**（确保由 v2 解释器启动）；也可以直接双击 `CodexMonitor.ahk`。脚本将驻留 Windows 系统托盘，此时尚未监控。
3. 切到 ChatGPT **桌面客户端**，保持窗口可见、不要被其他窗口覆盖。
4. 按 `Ctrl + Shift + F12` 启动，看到右上方“● 监控中”。再次按该组合键停止。
5. 要完全退出，在系统托盘找到 AutoHotkey 脚本图标，右键退出。

如需进行不操作桌面的基础自检，可用 AutoHotkey v2 执行 `CodexMonitor.ahk --self-test`；此模式测试基础判断逻辑后立即退出，不启动监控、不点击鼠标。

## 安全限制及注意事项

**请先人工验证脚本识别准确性，再交给无人值守的任务。** 特别是首次请观察监控日志，确认它仅在三角形出现时点击。

- 基于屏幕像素的颜色/形状识别，而不是 ChatGPT 内部 API。依据你提供的 **1759×2048** 两张截图校准：蓝色 `#2C67C5`、白色方形和朝右三角形。不同 UI 版本、Windows 缩放、皮肤、窗口过窄或新版图标可能无法识别；在这些情况下它应该选择不点击。
- 只作用于**当前前台的同一个 ChatGPT.exe 窗口**。如果切到其他窗口，会停止监控并弹出错误，而不是后台操纵鼠标。
- 软件可能在正常完成或其他状态时也显示三角形。此版本**无法语义区分**“任务已完成”和“意外中断”，仅按你指定的图标规则触发。
- 可见界面中覆盖图标的弹窗、鼠标指针、聊天内容等可能让识别失败；不会因失败强行点击。
- 按钮位置通过底部区域识别蓝色圆形自动定位，不直接使用固定屏幕坐标。需要它在屏幕中显示出来；最小化后不工作。
- 截图检测到三角形与真正点击之间始终存在极短时间差，不具备原子性，因此不保证绝对零误判。
- 如果暂停按钮本身没有完成状态切换，脚本会保持锁定，**不会无限重试**。
- 对 `Selected model is at capacity` 等服务端失败，只能尝试 UI 恢复，不能保证服务恢复或模型有可用容量。

## 故障排查

- **脚本打开不了**：确保安装 AutoHotkey v2，检查默认 `.ahk` 文件关联，右键选择 v2 解释器打开。
- **始终 unknown**：更新版 ChatGPT 的色彩、布局或缩放可能不同；先保持原截图所示的默认深色模式与桌面缩放。查看日志，不要通过放宽判定强行点击。
- **无法启动（非 ChatGPT）**：将真正的桌面版 ChatGPT 窗口置顶。浏览器网页打开 ChatGPT 不符合进程校验。
- **不再次触发**：点击后必须先持续识别到方形两轮（约 10～20 秒），才会解锁。这是为了防止重复点击的刻意设计。

## 检测逻辑

```text
Ctrl+Shift+F12
  ├─ 不是前台 ChatGPT.exe → 报错，停止
  └─ 是前台 ChatGPT.exe → 显示监控中
         ↓ 立即执行一次 + 每 10 秒
       无法识别 → 不操作
       识别方形 → 不操作；锁定状态时连续 2 次可解锁
       识别三角形 → 再确认 2 次 → 单击一次并锁定
         ↓
       直到重新确认方形 → 才重新允许下一次点击
```
